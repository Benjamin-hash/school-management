# 🏫 School Management System

A comprehensive, commercial-grade desktop application built with **JavaFX** and **SQLite** designed to streamline school administration. This system handles everything from student admissions and teacher assignments to term-based grading, fee management with installments, and printable report cards.

## ✨ Features

*   **Role-Based Access Control:** Distinct dashboards and permissions for Admins and Teachers.
*   **Student Admissions:** Add, update, and transfer students between classes.
*   **Class & Subject Management:** Define classes (Nursery to JHS) with specific sections (A, B, etc.).
*   **Homeroom Setup:** Bulk-assign a Primary/Nursery teacher to all subjects for a specific class.
*   **Fast Attendance:** One-click toggles for Present, Absent, and Late, complete with bulk actions and real-time totals.
*   **Term-Based Grading:** Enter and update scores by term and academic year. Automatically calculates letter grades (A-F).
*   **Fee Management:** Define fee structures per level/term, generate bills, and track partial payments (installments).
*   **Printable Receipts & Reports:** Generate modern report cards with attendance summaries and print fee receipts.
*   **Commercial Licensing System:** Built-in 8-month trial with anti-cheat clock tampering, and offline license key generation (Termly, Yearly, Lifetime).

## 🛠️ Technology Stack

*   **Language:** Java 17+
*   **UI Framework:** JavaFX 21
*   **Database:** SQLite (via JDBC)
*   **Build Tool:** Maven
*   **Architecture:** MVC (Model-View-Controller) with DAO Pattern
